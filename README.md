# Serifu Motion

セリフ音声から、アバターの表情・頭・胴体の動き（emo）を自動生成するWebアプリです。表情は感情ラベルやBlendShape名ではなく、FACS の Action Unit（AU）で記述します。

- **スタジオ**: 話者ごとの音声、または会話音声（自動で話者分離）を読み込むと、emo を生成して3Dアバターに適用します。話者別トラックのタイムラインでキー編集・感情の範囲指定・うなずき等の挿入ができます。emo JSON / AU CSV / 動画で書き出せます。
- **ライブ**: iPhone などのカメラとマイクで、リアルタイムにアバターを動かします。カメラから拾うのは瞬きと口の形だけで、表情・頭・胴体はマイク音声からリアルタイムに生成します。
- 言語非依存の韻律特徴（声の高さ・大きさ・間・スペクトル）を話者ごとに正規化して使うので、日本語・英語ほかどの言語の音声でも動きます。UIは日本語・英語・中文・한국어・Español・Français・Deutsch。

## 構成

| パス | 内容 |
|---|---|
| `app/` | Webアプリ本体（ビルド不要、静的ファイル）。GitHub Pages で公開 |
| `app/core/features.js` | 音声特徴抽出（学習時もこのファイルをNodeで使い、ブラウザと完全に同じ特徴にする） |
| `app/core/model.js` | 時間畳み込みネット（TCN）の推論。オフライン版と、低遅延の因果版（ストリーミング） |
| `app/core/generator.js` | 学習済みネット + データから推定した確率的レイヤー（瞬き、視線のサッケード、微細な揺れ） |
| `app/avatar/` | オリジナルの3Dアニメ調キャラクター4体と、AUで直接動くパラメトリック表情リグ |
| `train/` | 学習パイプライン（映像→AU/頭/胴体の数値抽出、学習、自己評価） |

## 学習データ

[CREMA-D](https://github.com/CheyneyComputerScience/CREMA-D)（Open Database License）: 俳優91人が12文を6感情で話した映像7,442本。映像そのものは保持・再配布せず、MediaPipe で抽出した数値（AU強度、頭部姿勢、肩の動き）と音声特徴だけを学習に使います。

## ローカルで動かす

```
cd app && python3 -m http.server 8000
```
